# Projetos de Disciplina em HTML

Desenvolvimento da Página Principal

o desenvolvimento do projeto teve o inicio com a criação e organização da pagina do site do Restaurante Mineiro, utilizando os  conhecimentos adquiridos nas aulas de HTML.

iniciallmente, realizei alterações na estrutura e na disposição do elementos da páginas, começando pelo titulo do site, O objetivo foi organizar melhor as informações apresentadas ao usuários de definir uma posição mais adequada para o conteúdo principal. 

Em seguida, realizei a centralização do nome "Restaurante Mineiro", dando maior destaque á identificação do estabelecimento logo no inicio da pagina. Essa alteração contribuiu para melhorar a organização visual e facilitar a identificação do site pelo visitante.

É também foi adicionada a logo do Restaurante, posicionada de forma a complementar a
identificação visual da página, A utilização da logo teve como objetivo tornar a página mais característica e aproximá-la da indentidade visual do estabelecimento real.
